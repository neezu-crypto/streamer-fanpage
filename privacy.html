스트리머 팬페이지 팬페이지로 돌아가기

PRIVACY

개인정보 처리방침

시행일: 2026년 11월 4일

스트리머 팬페이지(이하 “서비스”)는 인증 스트리머의 공개 페이지, 최근 방문, 영상 댓글 및 연동 콘텐츠를 제공합니다. 이 방침은 서비스가 실제로 처리하는 정보와 보유기간을 안내합니다.

1. 처리 항목과 목적

계정·로그인·인증

항목: Firebase UID, 로그인 제공자·연결 상태, 제공자가 전달하는 이메일 등 인증 정보, 스트리머 인증 상태.

목적: 로그인 세션 유지, 계정과 인증 스트리머 확인, 댓글 작성 권한과 페이지 관리 권한 검증, 보안·부정 이용 방지. 방문자는 페이지 열람과 롤링페이퍼 작성에 임시 익명 UID를 사용할 수 있습니다. 롤링페이퍼 작성자의 UID 원문은 공개 콘텐츠에 저장하지 않으며, 팬페이지별 작성 한도를 적용하기 위해 해시한 식별자와 당일 횟수를 서버에 보관합니다. 보호된 계정 기능은 Google·Kakao 등 계정 연결이 필요합니다.

브라우저 저장 정보

Firebase 로그인 상태는 브라우저 저장소에 유지됩니다. 카카오 계정 연결 UID는 로그아웃하거나 브라우저 데이터를 지울 때까지 localStorage에 저장됩니다. 계정 전환 요청의 중복 처리를 막는 요청 ID·시각과 로그인 보조 화면 상태는 localStorage 또는 sessionStorage에 기록하며, 재시도 제한 시간이 지나면 요청 ID는 더 이상 유효하게 사용하지 않습니다. 스티커 숨김 설정, 영상 재생 음량과 버튼 효과음 설정도 브라우저 localStorage에 저장될 수 있습니다. 브라우저 저장 정보를 지우면 로그인 상태가 풀리거나 일부 환경설정이 초기화될 수 있습니다. 서비스는 광고 추적용 쿠키를 사용하지 않지만 Firebase 인증이나 외부 로그인·미디어 제공자가 자체 저장 정보나 쿠키를 사용할 수 있으며 그 처리는 각 제공자 정책을 따릅니다.

팬페이지 공개 정보

항목: 인증 데이터의 스트리머 닉네임·SOOP 아이디·프로필 사진·SOOP 링크, 스트리머가 입력한 소개·프로필·일정·대회 이력·외부 링크·배너 이미지 주소, 노래책 영상, 직접 등록한 캘린더 일정과 주간 방송표(주차, 요일별 시간·내용·휴방 여부, 하단 문구, 템플릿·효과 설정, 공개 갤러리 이미지 ID), 업보 신청 항목과 팬 신청·승인 기록, 플레이한 게임의 이름·링크·최고기록 또는 최고랭크·연결한 다시보기와 선택적으로 연결한 게임 계정 검색 식별자(Riot ID, 오버워치 BattleTag, 배틀그라운드 게임 내 닉네임) 및 OP.GG 지역, 기억의 순간 제목·플랫폼·영상 ID·링크·썸네일, 롤링페이퍼 주제·메시지·선택 닉네임·작성 시각·공개 갤러리 이미지 주소, 응원 스티커 종류·보드 위치·부착 시각.

목적: 스트리머 페이지의 공개 표시, 검색, 일정·콘텐츠·팬 참여 기능 제공. 등록된 소개·일정·게임 기록·연결한 게임 계정 검색 식별자와 OP.GG 전적 링크·기념 영상 및 롤링페이퍼 메시지·선택 닉네임은 해당 팬페이지 방문자에게 공개됩니다. 게임 계정 식별자와 선택 지역은 스트리머가 직접 입력하며, 팬페이지가 계정 소유 여부를 확인하거나 전적을 조회·수집하지 않고 OP.GG 링크를 만드는 데 사용합니다. OP.GG 방문 시 해당 외부 서비스가 별도의 정보를 처리할 수 있습니다. 롤링페이퍼 닉네임을 비워 두면 익명으로 표시됩니다. 업보 미승인 신청은 해당 스트리머와 관리자만 확인합니다. 스티커 작성자의 계정 UID는 공개 스티커 항목에 저장하지 않고 서버에서 해시 식별자로 처리하며, 공개 보드에는 스티커와 위치만 표시합니다.

공통 즐겨찾기 영상 모음

항목: 관리자가 만든 카테고리 이름·정렬 순서, 개별 등록 영상·플래시게임 링크의 플랫폼·영상 ID(해당하는 경우)·제목·썸네일·링크, 관리자가 등록한 YouTube 채널 ID·이름·주소·썸네일과 해당 채널에서 가져온 공개 영상 메타데이터, SOOP 시네티의 고정 카테고리 ID·작품 ID·한국어 제목(제공되는 경우)·원제·썸네일 주소·서비스 상태, 동기화 시각, 등록·수정 시각과 관리용 등록 계정 식별자. 외부 플래시게임 페이지를 등록하면 서버가 공개 HTML의 제목·대표 이미지 주소를 읽어 저장할 수 있습니다. 시네티 목록 캐시에는 이용자 UID나 검색 기록을 저장하지 않습니다.

목적: 모든 스트리머 팬페이지에서 영상을 검색·열람하고 외부 플래시게임 페이지로 이동할 수 있게 하며, 관리자만 직접 관리하는 카테고리·개별 영상·플래시게임 링크·YouTube 채널을 등록·관리하고 공개 영상을 동기화합니다. SOOP 시네티의 애니메이션·영화·드라마 공개 작품 카테고리는 서버가 공개 목록을 받아 72시간 주기로 동기화해 공통으로 표시합니다. 이 데이터는 공통 즐겨찾기로 공개됩니다. 영상이나 게임 자체를 내려받아 저장하지 않으며, 공개된 작품·게임 페이지의 메타데이터·썸네일 주소와 외부 상세 주소를 처리합니다.

주간 방송표 이미지 업로드

항목: 인증 스트리머 또는 관리자가 주간 방송표에서 선택·업로드한 이미지와 썸네일, 이미지 분류·크기·업로더 계정 식별자, 업로드·등록 시각 및 갤러리 이미지 ID.

목적: 업로드한 이미지를 해당 스트리머 갤러리에 등록하고 방송표 아바타로 표시합니다. 업로드 파일과 썸네일은 스트리머 갤러리의 Cloudflare R2 저장소에 전송되고, 이미지 메타데이터는 갤러리 서비스에 저장됩니다. 등록된 이미지는 갤러리 공개 콘텐츠로 표시될 수 있으며, 방송표에는 해당 스트리머 갤러리의 공개 이미지만 연결할 수 있습니다.

스티커 표시 설정

이용자가 스티커를 숨기거나 다시 표시할 때 선택한 스티커 ID 또는 전체 숨김 설정을 브라우저 localStorage에 저장합니다. 이 표시 설정은 서버로 전송되지 않으며 브라우저 데이터를 지우면 초기화될 수 있습니다.

다마고치 디자인 신청

항목: 신청한 인증 스트리머의 계정 UID·공개 닉네임·SOOP 아이디, 신청 방식, 캐릭터 이름·디자인 설명·원하는 상호작용·참고 이미지 HTTPS 주소·추가 메모, 신청·검토 시각과 상태, 관리자의 검토 메모·계정 식별자.

목적: 인증 스트리머의 캐릭터 디자인 신청을 받고 관리자 검토 후 승인된 캐릭터 정보를 팬페이지에 공개합니다. 신청 내용과 검토 상태는 신청한 스트리머와 관리자만 확인할 수 있고, 승인된 캐릭터 이름·디자인 설명·상호작용 정보만 공개 프로필에 표시됩니다.

최근 방문 및 방문 통계

항목: Firebase UID별 최근 방문 팬페이지 최대 8개의 스트리머 아이디·방문 시각, 스트리머별 일일 조회·순방문 합계, 일일 중복 방문 집계용 UID 해시 키.

목적: 최근 방문 목록은 계정별로 서버에 저장하며 인증된 이용자는 본인 UID에 연결된 목록만 callable로 확인할 수 있습니다. 브라우저는 방문 기록 노드를 직접 읽을 수 없습니다. 일별 조회와 순방문은 합계로만 관리자 통계에 반환되며 방문자별 식별 정보는 통계 화면에 표시하지 않습니다. 관리자와 해당 스트리머 본인의 조회는 집계에서 제외합니다.

인증 스트리머 관리자 접속 알림

항목: 공개 닉네임·SOOP 아이디, 서비스 구분과 접속 시각. 서버는 인증 여부를 확인하기 위해 계정 UID를 처리하지만 새 접속 이벤트에는 UID를 기록하지 않습니다. 같은 SOOP 아이디는 하루 한 번 기록합니다.

목적: 관리자에게 인증 스트리머 접속을 알립니다. 이벤트 기록은 관리자만 읽을 수 있는 Firebase 경로에 저장하고, Discord 알림에는 공개 닉네임·SOOP 아이디·접속 시각만 전달합니다. 다른 이용자에게 개별 접속 기록을 제공하지 않습니다. 배포 전 생성된 과거 이벤트에 UID가 들어 있을 수 있으며, 해당 기록도 관리자 전용으로 제한됩니다. Firebase 기록은 운영자가 삭제할 때까지 보관하며 Discord 알림은 Discord의 보유 정책을 따릅니다.

VOD 댓글과 댓글 프로필

항목: 댓글 계정 UID, 이용자가 저장한 닉네임·선택 입력한 SOOP 아이디·프로필 이미지 주소, 댓글 내용과 작성 시각.

목적: 댓글 작성·표시와 스트리머·관리자의 댓글 관리. 팬페이지 댓글은 해당 VOD 페이지에서 공개되며 공개 닉네임과 이용자가 선택 입력한 SOOP 아이디가 표시됩니다. 댓글 저장에는 서버 관리용 UID가 포함되지만, 팬페이지 댓글 목록·등록 응답에는 Firebase UID를 반환하지 않습니다. SOOP VOD 댓글은 SOOP에서 요청 시 가져와 표시하며 팬페이지 데이터베이스에 복사해 보관하지 않습니다. SOOP가 공개하는 댓글 닉네임·아이디는 해당 플랫폼의 공개 정보입니다.

디자인 문의와 건의

항목: 인증 스트리머의 Firebase UID, 인증된 SOOP 닉네임·아이디·인증 시각, 문의 유형·제목·내용, 대상 스트리머 아이디·닉네임, 접수 시각과 처리 상태. 부정 이용 방지를 위해 UID별 하루 접수 횟수도 기록합니다.

목적: 팬페이지 디자인 변경 문의, 기능 건의와 오류 제보를 접수하고 관리자가 검토·처리합니다. 인증 스트리머만 제출할 수 있으며, 제출 내용은 공개되지 않고 관리자만 확인합니다. 새 접수가 있으면 문의 유형, 제출자의 인증된 공개 닉네임·아이디·인증 시각, 대상 스트리머의 공개 닉네임·아이디를 관리용 Discord 알림으로 전달합니다. 제목·본문·Firebase UID는 Discord로 보내지 않습니다.

스트리머 시리즈 통합 구독 인증

항목: 신청 계정 Firebase UID, 이용자가 입력한 SOOP 아이디, 신청·코드 발급·검토 시각, 코드 검증용 해시와 만료 시각, 신청 상태, 관리자의 확인 결과, SOOP 아이디와 계정의 연결 정보, 계정별 구독 만료 시각. 일회용 코드 원문은 발급 응답으로 한 번만 전달하고 서버에 저장하지 않습니다.

목적: 구독자 전용 게시글 댓글의 일회용 코드와 댓글 작성자의 공개 방송국 아이디를 대조하고, 관리자가 현재 SOOP 구독 상태를 확인해 스트리머 시리즈의 모든 구독자 전용 콘텐츠 이용 권한을 부여합니다. 고점체크의 기간별 최고 시청 순간 분석·같은 날 2명 비교·키워드 다중 비교는 운영 점검 기간에 관리자만 이용할 수 있도록 일시 제한됩니다. 그 외 현재 혜택은 갤러리의 잠긴 이미지 상세 원본 열람 및 다운로드, 주식시장의 매일 출석 보상 2배·하루 무료 복권 1장·월 홍보 이용권 5종(우측 배너 7일, 차트 배너 7일, 카드 배너 7일, 최상단 고정 12시간, 중계방 8시간)입니다. 주식시장 월 이용권은 KST 매월 1일 초기화되고 이월되지 않으며 보물상자 구독 무료 지급은 일시 중단되어 있습니다. 무료 복권 중복 수령 방지 및 재시도 복구를 위해 주식시장은 Firebase UID, KST 수령일, 복권 요청·처리 상태를 기록합니다. 보물상자 기능은 관리자 전용으로 재개 전까지 일반 사용자에게 제공되지 않으며, 통합 캐시 구매·보너스·잔여·개봉·취소 내역은 구매 처리, 구매 순서 보장, 중복 차감 방지, 7일 취소 자격 확인과 캐시 원장 대조를 위해 주식시장 서비스의 서버 전용 데이터베이스에 저장됩니다. 기존 상자 수량은 그대로 유지됩니다. 코드는 한 번만 쓸 수 있고 30분 후 만료되며, 새 코드 발급 시 이전 코드는 무효화됩니다. 승인된 SOOP 아이디는 Firebase 계정 한 곳에만 연결합니다. 구독 만료 시각은 관리자가 SOOP에서 확인해 입력합니다. 기존 별풍선 방식의 미처리 신청과 승인 이용권은 새 방식으로 소급 변경하지 않습니다. 월 홍보 이용권의 상품별 사용량·신청 내용·처리 및 반환 상태는 주식시장 서버 전용 데이터베이스에 따로 저장되며, 이 페이지는 해당 기록을 읽거나 보관하지 않습니다. SOOP 비밀번호·인증정보·쿠키를 수집하지 않고 SOOP 댓글을 자동 수집하지 않습니다. 신청·연결·구독 데이터는 Firebase Realtime Database에 서버 전용으로 저장되어 브라우저가 직접 읽거나 쓸 수 없습니다. 신청 코드 해시와 검토 이력은 중복 인증 방지·문의 대응을 위해 필요한 기간 동안 보관합니다.

신청 알림: 통합관리센터가 열린 동안 관리자 권한으로 새 신청의 요청 ID와 접수 시각만 포함된 작은 신호를 실시간 확인합니다. 신청자 UID·SOOP 아이디·인증 코드·댓글 내용은 이 신호에 포함되지 않으며, 관리자가 신청 목록을 열거나 새로고침할 때 서버 callable을 통해 세부 정보를 조회합니다.

오늘의 후원 스트리머 홍보 신청

항목: 신청 Firebase UID, 홍보할 스트리머의 닉네임·SOOP 아이디, 후원자 SOOP 아이디, 선택한 홍보 일수·별풍선 수량, 신청·후원 완료·승인·반려 시각과 상태, 홍보 시작·종료 시각. 부정 이용 방지를 위해 UID별 마지막 신청 시각도 기록합니다. 과거 자동 확인 기능 운영 중 생성된 진단 기록은 기존 운영 이력으로 남을 수 있으며 새 후원 알림 대조 정보는 생성하지 않습니다.

목적: 홍보 신청 중복을 막고 후원 완료 신호를 참고해 관리자가 후원 내역을 수동 확인하고 홍보 카드를 승인·표시합니다. SOOP 후원 알림은 자동 감시하거나 자동 승인에 사용하지 않습니다. 후원 완료 알리기를 전달하지 않은 신청은 7일 후 만료됩니다. 신청·결제 확인 정보는 Firebase Realtime Database에 서버 전용으로 저장되어 브라우저가 직접 읽거나 쓸 수 없습니다. 공개 페이지에는 승인된 스트리머의 닉네임, SOOP 아이디, 공개 프로필 이미지·방송국 주소, 좌우 노출 영역과 홍보 시작·종료 시각을 반환합니다. 신청자 UID와 후원자 아이디는 공개 카드에 포함되지 않습니다. SOOP 로그인 정보, 쿠키, 알림 전체 본문은 서버로 보내지 않으며, SOOP 공식 API나 웹훅을 이용한 확인도 아닙니다.

고점체크 검색·집계 요청

항목: 해시 처리한 계정 식별자, 익명·로그인·구독·관리자 이용 등급, 요청 종류별 횟수, 선택한 스트리머 SOOP 아이디, 집계 작업 상태·대기 시간·결과.

목적: UID 해시 키로 요청 한도를 적용하고 최근 사용량을 관리합니다. 관리자 화면은 최근 30일의 합계와 스트리머별 집계만 보여 주며 개인별 기록은 반환하지 않습니다. 검색어와 원본 Firebase UID는 고점체크 사용 통계에 저장하지 않습니다. 개별 대기열 결과는 요청한 계정만 callable로 확인하고, 다른 계정의 결과 요청은 서버가 거부합니다. RTDB는 브라우저에서 직접 읽거나 쓸 수 없습니다. 성공한 다시보기 분석 결과는 재분석과 반복 서버 조회를 줄이기 위해 RTDB에 공유 캐시로 저장합니다. GitHub Actions가 하루 한 번 완료된 캐시를 읽어 스트리머 아이디·VOD 아이디, 최고·최저 시청자 수와 시점, 확인 시각만 공개 정적 파일로 내보냅니다. 평균 시청자 수 등 구독 전용 지표, 원본 그래프, 계정·신청 정보는 정적 파일에 포함하지 않으며, 구독 전용 기간 분석·비교 요청은 운영 점검 기간에 관리자 권한을 서버에서 확인합니다. 파일은 GitHub Pages에서 누구나 열람할 수 있습니다.

관리자용 팬페이지·시청 통계 스냅샷

관리자 통계는 최근 30일의 팬페이지별 조회·순방문 합계, 인증 스트리머 목록·공개 닉네임, 시청 통계 기능의 이용 등급·작업량·처리 시간·전송량 및 스트리머별 검색 횟수를 집계합니다. 개별 방문 UID·UID 해시·IP 주소·검색어는 스냅샷에 포함하지 않습니다. 관리자용 스냅샷은 접근이 제한된 Google Cloud Storage에 저장되고 약 1시간마다 갱신되며, 관리자 권한을 확인한 서버 기능을 통해서만 조회됩니다.

외부 콘텐츠와 캐시

항목: 스트리머의 SOOP 아이디·VOD ID·공개 채널 주소·카페 주소·위플랩 공유 주소와 SOOP·YouTube 공개 영상/채널·게시글·일정·갤러리 콘텐츠 메타데이터.

목적: SOOP 방송 상태·캘린더·다시보기와 SOOP 시네티 공개 작품 목록, 네이버 카페 공개 게시글, YouTube 공개 영상, 위플랩 공개 룰렛, 스트리머 갤러리 공개 이미지의 조회와 캐시. SOOP VOD 목록은 최신 500개 범위에서 갱신되며, 캘린더는 10분, 스트리머 YouTube 영상 목록은 30분, 카페 미리보기는 5분, 위플랩 룰렛은 1분 캐시를 적용합니다. 공통 영상 모음의 YouTube 채널과 시네티 공개 작품 목록은 주기적으로 동기화합니다. 공개 SOOP VOD 댓글은 요청 때 조회합니다.

2. 보유기간과 삭제

보유기간이 끝나거나 처리 목적이 달성되어 더 이상 보관할 필요가 없는 정보는 운영자가 법령상 보존 필요 여부를 확인한 뒤 서비스가 관리하는 Firebase 데이터베이스나 Google Cloud Storage에서 삭제합니다. 주간 방송표에 연결된 갤러리 파일은 갤러리 서비스의 삭제 절차로 처리하며, 방송표에서 연결을 해제하는 것만으로 파일이 삭제되지는 않습니다. 공개 정적 자료는 생성 파일에서 제거한 뒤 Pages 배포로 교체합니다. 외부 제공자의 접속 로그·백업 등은 해당 제공자의 정책을 따릅니다.

  • 최근 방문 목록은 계정별 최대 8개이며 새 페이지를 방문하면 가장 오래된 항목을 교체합니다. 별도 시간 만료는 없으며 삭제 요청은 아래 문의처로 접수할 수 있습니다.
  • 공개 팬페이지 설정, 직접 등록 일정·주간 방송표, 게임·최고기록, 기억의 순간, 승인된 업보 기록, 팬페이지 댓글, 롤링페이퍼 메시지·주제 및 스티커는 스트리머·관리자가 수정·삭제하거나 운영상 정리할 때까지 보관합니다. 공통 즐겨찾기 영상 모음은 관리자만 수정·삭제할 수 있으며 운영상 정리할 때까지 보관합니다. 롤링페이퍼 작성 한도용 해시 식별자와 당일 횟수는 이후 작성 시 갱신되며 공개되지 않습니다. 스티커 부착 계정의 해시 식별자는 계정별 중복 부착·소유자 확인에 사용되며 스티커가 삭제될 때 함께 정리됩니다. 업보 미승인 신청은 스트리머가 승인·반려할 때까지 보관합니다. 별도 자동 만료 기간이 없는 항목의 삭제 요청은 아래 문의처로 접수할 수 있습니다.
  • 주간 방송표 이미지 업로드 파일·썸네일과 갤러리 메타데이터는 해당 스트리머 갤러리에 등록되어 갤러리의 삭제·보관 기준을 따릅니다. 방송표에서 이미지를 연결 해제해도 갤러리 이미지 자체가 자동 삭제되지는 않습니다.
  • 구독 만료 정보와 신청·승인 이력, 후원자 닉네임은 재구독 기간 연장·후원 확인·문의 처리에 필요한 기간 동안 보관하며, 삭제 요청이나 서비스 종료 시 운영자가 정리합니다.
  • 홍보 신청 정보와 처리 이력은 중복 신청 방지·후원 확인·문의 대응을 위해 보관합니다. 후원 완료 전 신청은 7일 후 만료되어 중복 신청 제한에서 해제됩니다. 후원 완료를 알린 대기 신청은 운영자가 승인·반려할 때까지 보관합니다. 승인된 홍보 카드는 최대 30일 노출되며 종료된 뒤에는 공개 목록에서 제외됩니다. 관련 이력은 삭제 요청 또는 서비스 종료 시 운영자가 정리합니다.
  • 디자인 문의·건의는 관리자가 삭제하거나 정보주체가 삭제를 요청할 때까지 보관합니다. UID별 접수 제한 기록은 해당 UID의 마지막 접수 날짜와 하루 접수 횟수만 저장하며 다음 날짜에 새 접수가 이뤄지면 갱신됩니다.
  • 고점체크 관리자 집계는 최근 30일 자료만 표시합니다. 대기 중·완료된 집계 요청과 임시 결과는 요청 일자 기준 약 3일 이내 자동 삭제됩니다. 사용량의 UID 해시 키는 요청 한도 적용을 위해 보관하며 개인별 내역은 관리자 화면에 표시하지 않습니다.
  • 완료된 다시보기 고점 통계는 재사용을 위해 RTDB 공용 캐시에 별도 만료 없이 저장합니다. 공개 정적 파일은 하루 한 번 다시 생성되며, 캐시 항목이 운영상 삭제되면 다음 생성 때 공개 파일에서도 제외됩니다.
  • 팬페이지의 일별 조회·순방문 집계와 해시 방문 키는 최근 30일 범위로 정리합니다. 누적 조회 수는 식별자를 포함하지 않는 합계로 보관합니다.
  • 관리자 통계 스냅샷은 최근 30일 집계 자료를 담고 비공개 Google Cloud Storage 객체 하나를 주기적으로 교체합니다. 원본 조회 자료의 보유기간은 위 항목에 설명한 기준을 따릅니다.
  • 다마고치 신청·검토 정보는 검토와 신청 이력 관리에 필요한 기간 동안 보관합니다. 같은 스트리머의 신청 이력은 최대 20건으로 관리하고, 한도를 넘길 때 오래된 반려 이력을 정리할 수 있습니다. 승인된 캐릭터 프로필은 운영자가 수정하거나 삭제할 때까지 공개될 수 있습니다.
  • 인증 스트리머 접속 이벤트는 Firebase에서 별도 자동 만료 없이 보관하며 운영자가 삭제할 수 있습니다. 하루 중복 방지 키는 다음 날 정리 작업에서 삭제합니다. Discord로 전달된 알림의 보유기간은 Discord 및 관리자 서버의 정책을 따릅니다.
  • 외부 콘텐츠 캐시는 각 항목에 안내한 시간 또는 다시보기 목록 갱신 시 교체됩니다. 시네티 작품 목록은 서버 데이터베이스에 저장하고 72시간마다 새 공개 목록으로 교체하며, 갱신 실패 시 기존 캐시를 유지합니다. 외부 원본은 SOOP·YouTube·네이버·위플랩·스트리머 갤러리의 정책과 보관기간을 따릅니다.
  • Firebase 로그인 계정과 외부 제공자가 자체 보안 목적으로 생성하는 접속 기록은 해당 제공자의 보유기간을 따를 수 있습니다. 법령상 보존 의무가 있는 정보는 해당 기간 동안 분리 보관합니다.

3. 처리위탁·외부 제공자와 국외 처리

Google LLC / Firebase

Firebase Authentication, Realtime Database, Cloud Functions와 App Check를 제공합니다. 팬페이지가 관리하는 콘텐츠·방문 목록·댓글·통계·요청 데이터는 팬페이지 전용 Realtime Database에 저장하고, 로그인 계정·인증 스트리머 확인 및 갤러리 공개 이미지 확인에는 생태계 공용 Realtime Database의 필요한 정보를 조회합니다. 브라우저에서 직접 접근하지 않고 서버 기능으로 처리하는 데이터가 있습니다. Firebase는 요청 처리 과정에서 접속 정보와 브라우저 환경 신호를 처리할 수 있습니다. Cloud Functions는 미국 us-central1 리전에서 운영됩니다. 데이터베이스 저장 위치는 각 Firebase 데이터베이스 인스턴스 설정을 따릅니다.

Google Cloud Storage

관리자용 최근 30일 통계 스냅샷을 비공개 객체로 저장합니다. 객체는 관리자에게 통계를 제공하기 위해 주기적으로 교체되며 공개 웹페이지나 일반 이용자에게 제공되지 않습니다.

GitHub, Inc. / GitHub Pages

정적 웹사이트를 호스팅합니다. 페이지 접속 과정에서 IP 주소·브라우저·접속 시각 등 기술 정보가 제공자 인프라에서 처리될 수 있으며, 호스팅은 글로벌 네트워크를 사용할 수 있습니다.

Kakao Corp., Google LLC 및 Google Fonts

Kakao SDK 또는 Google 로그인을 이용자가 선택한 경우 인증을 처리합니다. 웹 글꼴은 브라우저와 운영체제에 설치된 기본 글꼴을 사용하며 Google Fonts를 요청하지 않습니다. 로그인 제공자가 처리하는 정보와 보유기간은 각 제공자 정책을 따릅니다.

SOOP, YouTube·Google, 네이버, 위플랩, Cloudflare R2 및 스트리머 갤러리

공개 방송·영상·카페·룰렛 데이터를 조회하고 공개 갤러리 이미지와 YouTube 영상을 표시하는 데 사용합니다. 후원 스트리머 카드의 프로필 이미지와 라이브 방송 미리보기도 SOOP 공개 리소스에서 불러옵니다. 주간 방송표의 인증 스트리머 이미지 업로드는 스트리머 갤러리의 업로드 기능을 사용하며, 원본·썸네일 파일은 Cloudflare R2로, 이미지 메타데이터는 갤러리 서비스로 전송됩니다. 롤링페이퍼 메시지에서는 공개 갤러리 이미지를 선택할 수 있습니다. 공개 SOOP VOD 목록과 통계 데이터는 서버가 요청하므로 이 요청에서 이용자의 IP 주소를 SOOP에 직접 전달하지 않습니다. 브라우저가 외부 이미지·영상·링크를 직접 열면 해당 제공자에게 IP 주소 등 접속 정보가 전달될 수 있습니다.

Discord

관리용 웹훅 알림을 전달합니다. 팬페이지 디자인 문의·건의가 접수되면 문의 유형과 대상 스트리머의 공개 닉네임·아이디만 알림에 포함하며, 제출 제목·본문·Firebase UID는 전송하지 않습니다. 인증 스트리머가 팬페이지에 접속하면 공개 닉네임과 SOOP 아이디를 접속 알림으로 관리자에게 전달합니다. 방문자의 Firebase UID와 IP는 이 알림에 포함하지 않습니다.

국외 처리·이전의 상세

  • Google LLC / Firebase·Google Cloud: 팬페이지 전용·공용 Realtime Database와 Cloud Functions는 미국 아이오와(us-central1)에서 운영됩니다. 계정·인증 정보, 팬페이지 콘텐츠와 요청 데이터는 로그인·페이지 기능 이용 시 HTTPS/API 요청으로 전송·처리됩니다. 관리자 통계 스냅샷은 미국 아이오와(us-central1)의 Google Cloud Storage에 약 1시간마다 HTTPS/API 방식으로 갱신됩니다. 이용 목적과 보유기간은 위 각 항목과 제2항을 따릅니다. 관련 Google 기능을 이용하지 않으면 로그인·데이터 조회·관리 기능의 일부가 작동하지 않을 수 있습니다.
  • GitHub, Inc. / GitHub Pages: 페이지 접속 때 IP 주소·브라우저 정보·접속 시각·요청한 페이지와 파일이 HTTPS로 전송되어 사이트 호스팅과 전달에 사용됩니다. 미국에 소재한 제공자의 글로벌 네트워크에서 처리되며 실제 전달 위치는 접속 경로에 따라 달라질 수 있고, 접속 로그 보유기간은 GitHub 정책을 따릅니다. 이 처리를 거부하면 사이트에 접속할 수 없습니다.
  • Cloudflare, Inc. / R2: 방송표 이미지 업로드 시 원본과 썸네일 파일이 서명된 HTTPS 업로드 주소를 통해 R2로 전송되고, 이미지를 표시할 때 브라우저가 공개 파일을 요청합니다. 이미지 ID·URL·분류·크기·업로더 계정 식별자 등 갤러리 메타데이터는 Google LLC가 운영하는 생태계 공용 Realtime Database(미국 아이오와 us-central1)에 HTTPS/API로 저장됩니다. R2 저장 위치는 Cloudflare 계정의 버킷 위치 설정에 따릅니다. 팬페이지 소스는 위치를 지정하지 않으며 자동 위치 선택 또는 버킷 설정에 따라 국가·지역이 달라질 수 있습니다. 이용 목적과 보유기간은 방송표 이미지 업로드 항목을 따르고, 업로드·표시를 거부하면 해당 이미지 기능을 사용할 수 없습니다.
  • Discord, Inc.: 관리 알림이 발생할 때 HTTPS 웹훅으로 문의 유형과 대상 스트리머의 공개 닉네임·SOOP 아이디, 또는 인증 스트리머의 공개 닉네임·SOOP 아이디·접속 시각을 전송합니다. Discord의 글로벌 서비스 인프라에서 처리될 수 있으며, 보유기간은 Discord 정책을 따릅니다. 문의 본문·Firebase UID·방문자 IP는 알림에 포함하지 않습니다.
  • 외부 콘텐츠 제공자: 브라우저에서 YouTube 영상·외부 이미지·링크를 직접 열면 요청 시 IP 주소·브라우저 정보·요청한 콘텐츠 주소가 해당 제공자의 인프라로 전송될 수 있습니다. 제공 국가와 보유기간은 제공자 및 콘텐츠 종류에 따라 달라집니다. 외부 콘텐츠를 열지 않으면 해당 요청은 발생하지 않으며, 일부 미리보기·재생은 사용할 수 없습니다.

서비스 화면은 제3자 글꼴을 불러오지 않습니다. 외부 제공자가 자체 보안 목적으로 생성하는 접속 정보는 각 제공자의 정책과 인프라를 따릅니다.
