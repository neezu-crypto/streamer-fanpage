개인정보 처리방침

시행일: 2026년 10월 17일

스트리머 팬페이지(이하 “서비스”)는 인증 스트리머의 공개 페이지, 최근 방문, 영상 댓글 및 연동 콘텐츠를 제공합니다. 이 방침은 서비스가 실제로 처리하는 정보와 보유기간을 안내합니다.

1. 처리 항목과 목적

계정·로그인·인증

항목: Firebase UID, 로그인 제공자·연결 상태, 제공자가 전달하는 이메일 등 인증 정보, 스트리머 인증 상태.

목적: 로그인 세션 유지, 계정과 인증 스트리머 확인, 댓글 작성 권한과 페이지 관리 권한 검증, 보안·부정 이용 방지. 방문자는 페이지 열람 과정에서 임시 익명 UID가 생성될 수 있습니다. 익명 세션은 공개 페이지 열람을 지원하며 보호된 계정 기능은 Google·Kakao 등 계정 연결이 필요합니다.

브라우저 저장 정보

Firebase 로그인 상태는 브라우저 저장소에 유지됩니다. 카카오 계정 연결 UID는 로그아웃하거나 브라우저 데이터를 지울 때까지 localStorage에 저장됩니다. 계정 전환 요청의 중복 처리를 막는 요청 ID·시각도 localStorage에 기록하며, 재시도 제한 시간인 20초가 지나면 더 이상 유효하게 사용하지 않습니다. 브라우저 저장 정보를 지우면 로그인 상태가 풀리거나 일부 계정 연결 표시가 초기화될 수 있습니다.

팬페이지 공개 정보

항목: 인증 데이터의 스트리머 닉네임·SOOP 아이디·프로필 사진·SOOP 링크, 스트리머가 입력한 소개, 생일, MBTI, 전공, 데뷔일, 팬·팬덤 이름, 관심 콘텐츠, 일정 안내, 네이버 카페·YouTube·위플랩 링크, 직접 등록한 일정, 업보 신청 항목 이름·설명·이미지 주소, 팬이 제출한 닉네임·항목·수량·신청 시각 및 승인된 업보 기록.

목적: 스트리머 페이지의 공개 표시, 검색, 캘린더·콘텐츠 기능 제공. 미승인 업보 신청은 해당 스트리머와 관리자만 확인하며, 승인된 기록은 해당 팬페이지 방문자에게 공개됩니다.

최근 방문 및 방문 통계

항목: 방문자 UID와 스트리머 아이디·방문 시각, 일별 페이지 조회 수, UID와 스트리머 아이디를 결합해 만든 일별 해시 방문 키.

목적: 최근 방문 페이지를 표시하고 스트리머별 방문 통계를 집계합니다. 스트리머 본인과 관리자의 페이지 열람은 방문 통계에서 제외합니다. 일별 해시 키와 일별 세부 통계는 최근 30일 범위로 관리하고, 누적 조회 수는 합계로 보관합니다. 통계 화면에는 방문자 UID나 해시 키를 제공하지 않습니다.

VOD 댓글과 댓글 프로필

항목: 댓글 계정 UID, 이용자가 저장한 닉네임·선택 입력한 SOOP 아이디·프로필 이미지 주소, 댓글 내용과 작성 시각.

목적: 댓글 작성·표시와 스트리머·관리자의 댓글 관리. 팬페이지 댓글은 해당 VOD 페이지에서 공개됩니다. SOOP VOD 댓글은 SOOP에서 요청 시 가져와 표시하며 팬페이지 데이터베이스에 복사해 보관하지 않습니다. 팬페이지 댓글 목록 응답에는 작성자를 식별하기 위한 UID가 포함될 수 있습니다.

디자인 문의와 건의

항목: 인증 스트리머의 Firebase UID, 인증된 SOOP 닉네임·아이디·인증 시각, 문의 유형·제목·내용, 대상 스트리머 아이디·닉네임, 접수 시각과 처리 상태. 부정 이용 방지를 위해 UID별 하루 접수 횟수도 기록합니다.

목적: 팬페이지 디자인 변경 문의, 기능 건의와 오류 제보를 접수하고 관리자가 검토·처리합니다. 인증 스트리머만 제출할 수 있으며, 제출 내용은 공개되지 않고 관리자만 확인합니다. 새 접수가 있으면 문의 유형, 제출자의 인증된 공개 닉네임·아이디·인증 시각, 대상 스트리머의 공개 닉네임·아이디를 관리용 Discord 알림으로 전달합니다. 제목·본문·Firebase UID는 Discord로 보내지 않습니다.

고점체크 구독 신청과 이용 권한

항목: 신청 계정 Firebase UID, 이용자가 입력한 후원자 SOOP 닉네임·아이디, 신청·후원 완료·처리 시각, 신청 상태, 후원 알림 대조 결과와 이벤트 식별값, 관리자 UID, 계정별 구독 만료 시각. 관리자 브라우저 확장 프로그램은 로그인된 SOOP 알림에서 발신 SOOP 아이디·별풍선 수량·시각 범위와 알림 식별용 해시를 확인합니다.

목적: 별풍선 후원 신청을 확인해 30일 이용 권한을 부여·연장하고, 구독 기간별 최고 시청 순간과 평균 대비 상승폭 기능의 권한을 확인합니다. 후원자 아이디·수량·신청 및 후원 완료 시각이 하나의 신청에 정확히 일치하면 자동 승인하며, 중복되거나 불확실한 경우 관리자가 수동 확인합니다. SOOP 로그인 정보, 쿠키, 알림 전체 본문은 서버로 보내지 않습니다. 구독 신청과 만료 데이터는 Firebase Realtime Database에 서버 전용으로 저장되며 브라우저에서 직접 읽거나 쓸 수 없습니다. 계정별 만료 시각과 신청 이력은 재구독 기간 연장·후원 확인·문의 처리에 필요한 기간 동안 보관하며, 삭제 요청 또는 서비스 종료 시 운영자가 정리합니다.

고점체크 검색·집계 요청

항목: 해시 처리한 계정 식별자, 익명·로그인·구독·관리자 이용 등급, 요청 종류별 횟수, 선택한 스트리머 SOOP 아이디, 집계 작업 상태·대기 시간·결과.

목적: 이용 한도를 적용하고 스트리머별 검색·선택량, 대기열 처리 상태와 서비스 사용량을 관리자 화면에 집계합니다. 검색어와 원본 Firebase UID는 사용 통계에 저장하지 않습니다. 다시보기 통계 작업 결과는 요청한 계정만 callable로 확인할 수 있고, RTDB는 서버에서만 접근합니다.

외부 콘텐츠와 캐시

항목: 스트리머의 SOOP 아이디·VOD ID·공개 채널 주소·카페 주소·위플랩 공유 주소, 공개 일정·게시글·영상·갤러리 콘텐츠.

목적: SOOP 방송 상태·캘린더·다시보기, 네이버 카페 공개 게시글, YouTube 공개 영상, 위플랩 공개 룰렛, 스트리머 갤러리 공개 이미지의 조회와 캐시. SOOP VOD 목록은 최신 500개 범위에서 갱신되며, 캘린더는 10분, YouTube 영상은 30분, 카페 미리보기는 5분, 위플랩 룰렛은 1분 캐시를 적용합니다. 공개 SOOP VOD 댓글은 요청 때 조회합니다.

2. 보유기간과 삭제

  • 최근 방문 목록은 계정별 최대 8개만 저장하고 새 페이지 방문 때 오래된 항목을 밀어냅니다. 별도 시간 만료 기간은 두지 않습니다.
  • 공개 팬페이지 설정, 직접 등록 일정, 승인된 업보 기록과 팬페이지 댓글은 스트리머 또는 관리자가 삭제하거나 수정할 때까지 보관합니다. 업보 미승인 신청은 스트리머가 승인·반려할 때까지 보관합니다. 자동 만료 기간은 없습니다. 삭제·탈퇴 요청은 아래 문의처로 접수할 수 있습니다.
  • 구독 만료 정보와 신청·승인 이력, 후원자 닉네임은 재구독 기간 연장·후원 확인·문의 처리에 필요한 기간 동안 보관하며, 삭제 요청이나 서비스 종료 시 운영자가 정리합니다.
  • 디자인 문의·건의는 관리자가 삭제하거나 정보주체가 삭제를 요청할 때까지 보관합니다. UID별 접수 제한 기록은 해당 UID의 마지막 접수 날짜와 하루 접수 횟수만 저장하며 다음 날짜에 새 접수가 이뤄지면 갱신됩니다.
  • 고점체크 사용량 기록은 최근 30일 범위로 정리합니다. 대기 중·완료된 집계 요청과 임시 결과는 요청 일자 기준 약 3일 이내 자동 삭제됩니다.
  • 방문 통계의 일별 해시 방문 키와 일별 집계는 최근 30일 범위로 정리합니다. 오래된 날짜 자료는 이후 방문 통계가 기록될 때 정리될 수 있습니다. 누적 조회 수는 식별자를 포함하지 않는 합계로 보관합니다.
  • 외부 콘텐츠 캐시는 각 항목에 안내한 시간 또는 다시보기 목록 갱신 시 교체됩니다. 외부 원본은 SOOP·YouTube·네이버·위플랩·스트리머 갤러리의 정책과 보관기간을 따릅니다.
  • Firebase 로그인 계정과 외부 제공자가 자체 보안 목적으로 생성하는 접속 기록은 해당 제공자의 보유기간을 따를 수 있습니다. 법령상 보존 의무가 있는 정보는 해당 기간 동안 분리 보관합니다.

3. 처리위탁·외부 제공자와 국외 처리

Google LLC / Firebase

Firebase Authentication, Realtime Database와 Cloud Functions를 제공합니다. 계정·인증, 팬페이지 설정·최근 방문·댓글·통계와 서비스 요청 처리를 위해 사용합니다. 데이터베이스와 서버 기능은 미국 us-central1 리전에서 운영됩니다.

GitHub, Inc. / GitHub Pages

정적 웹사이트를 호스팅합니다. 페이지 접속 과정에서 IP 주소·브라우저·접속 시각 등 기술 정보가 제공자 인프라에서 처리될 수 있으며, 호스팅은 글로벌 네트워크를 사용할 수 있습니다.

Kakao Corp., Google LLC 및 Google Fonts

Kakao SDK 또는 Google 로그인을 이용자가 선택한 경우 인증을 처리하고, 웹 글꼴을 불러올 때 Google Fonts를 사용합니다. 로그인 제공자가 처리하는 정보와 보유기간은 각 제공자 정책을 따릅니다.

SOOP, YouTube·Google, 네이버, 위플랩, Cloudflare 및 스트리머 갤러리

공개 방송·영상·카페·룰렛 데이터를 조회하거나 공개 갤러리 이미지를 표시하는 데 사용합니다. 팬페이지는 별도 이미지 업로드 기능을 제공하지 않으며 스트리머 갤러리에 공개된 이미지 주소를 표시합니다. 외부 플레이어·이미지를 브라우저에서 열면 해당 제공자가 접속 정보와 이용 기록을 처리할 수 있습니다. 외부 콘텐츠 요청에는 주로 대상 스트리머의 공개 아이디나 공개 콘텐츠 주소가 사용됩니다.

Discord

관리용 웹훅 알림을 전달합니다. 팬페이지 디자인 문의·건의가 접수되면 문의 유형과 대상 스트리머의 공개 닉네임·아이디만 알림에 포함하며, 제출 제목·본문·Firebase UID는 전송하지 않습니다.

Firebase 데이터는 미국 리전에서 처리될 수 있습니다. 외부 로그인, 글꼴, 영상 플레이어, 이미지 또는 링크를 이용하면 각 제공자의 글로벌 인프라에서 접속 정보가 처리될 수 있습니다. 제공자의 자체 접속 로그 보유기간은 서비스가 통제하지 않습니다.

4. 정보주체의 권리

이용자는 본인 정보의 열람·정정·삭제·처리정지를 요청할 수 있습니다. 댓글·최근 방문 정보는 UID를 기준으로 확인하므로 본인 확인 자료가 필요할 수 있습니다. 삭제를 요청할 때 서비스 전용 데이터인지 공유 자매 서비스의 계정 데이터인지 범위를 알려 주세요. 법령상 보존 의무 또는 다른 이용자 권리 보호가 필요한 경우 일부 처리가 제한될 수 있습니다.
