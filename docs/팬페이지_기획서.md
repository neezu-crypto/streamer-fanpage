# 스트리머 팬페이지 기획서

작성일: 2026-10-06  
서비스 주소: https://neezu-crypto.github.io/streamer-fanpage/

## 1. 서비스 목표

인증 스트리머마다 팬 전용 페이지를 제공한다. 팬은 스트리머를 검색하거나 최근 방문 기록으로 페이지를 다시 찾고, 스트리머는 서버 인증을 마친 뒤 본인 페이지를 직접 관리한다.

핵심 원칙:

- 페이지 소유권은 서버가 공유 인증 데이터로 확인한다.
- 스트리머의 활동·공지·콘텐츠를 한곳에서 찾기 쉽게 보여준다.
- 모바일에서 주요 정보와 이동 버튼을 먼저 보여준다.
- 팬페이지 전용 데이터는 공유 Firebase 프로젝트의 서버 경로에 저장하고, 읽기·쓰기는 Cloud Functions를 통한다.

## 2. 현재 구현된 기능

- 일반 사용자: 인증 스트리머 검색, 팬페이지 열람, 최근 방문한 페이지 8개 확인
- 로그인: Google·카카오 계정 연결 및 로그인, 스트리머 인증 신청·확인
- 인증 스트리머: 서버가 본인 SOOP ID를 확인해 해당 팬페이지로 자동 이동
- 페이지 편집: 인증 스트리머가 팬페이지 소개글을 수정
- 공통 이동: 공유 `devbarLinks`를 읽어 자매 서비스 바로가기 표시
- 시작 화면: 인증과 페이지 데이터, 폰트·이미지 로드가 끝난 뒤 안내 화면을 닫음

## 3. 권장 팬페이지 구성

페이지는 다음 순서로 배치한다.

1. **프로필과 바로가기** — 프로필 이미지, 닉네임, 인증 표시, SOOP 아이디, 방송국 방문 버튼
2. **고정 공지** — 현재 진행 중인 안내나 팬에게 필요한 소식을 상단에 표시
3. **방송 일정** — 다음 방송 시간과 정기 일정을 간단한 목록으로 표시
4. **스트리머 소개** — 현재 구현된 소개글 편집 기능을 사용
5. **추천 콘텐츠** — 대표 VOD와 스트리머 갤러리 등 외부 콘텐츠 연결
6. **팬 소통** — 스트리머 메신저나 공식 방송국으로 이동하는 링크 제공

빈 섹션은 팬에게 빈 카드로 보이지 않도록 숨긴다. 스트리머가 입력하지 않은 공지·일정·추천 콘텐츠는 공개 페이지에서 표시하지 않는다.

## 4. 단계별 우선순위

### 1단계 — 정보성 섹션

- 공지 1개 이상 등록·수정·삭제
- 방송 일정 등록·수정·삭제
- 지난 일정과 종료 공지를 숨기거나 보관하는 기준 마련
- 공개 페이지에서 게시 순서와 표시 상태 확인

**완료 기준:** 인증 스트리머만 본인 페이지의 공지와 일정을 편집할 수 있고, 방문자는 최신 정보만 모바일에서도 읽기 쉽게 볼 수 있다.

### 2단계 — 추천 콘텐츠와 소통 링크

- SOOP VOD, 방송국 게시판, 스트리머 갤러리의 대표 콘텐츠 링크 등록
- 메신저 채팅방 등 이미 운영 중인 자매 서비스 연결
- 외부 링크는 HTTPS만 허용하고 새 탭으로 열기

**완료 기준:** 링크 제목과 주소가 명확하고, 잘못되거나 비어 있는 링크는 공개 화면에 나타나지 않는다.

### 3단계 — 편집 편의 개선

- 페이지 섹션 표시 여부와 순서 조정
- 편집 미리보기와 저장 결과 확인
- 최근 수정 시각 표시

**완료 기준:** 스트리머가 모바일에서도 소개·공지·일정의 공개 상태와 순서를 쉽게 관리한다.

## 5. 데이터·권한 원칙

현재 팬페이지 데이터 경로는 `streamerFanPages/{soopId}`다. 현재 저장 필드는 `intro`, `updatedAt`이며 소개글 저장은 `streamerFanPageSave`가 처리한다.

추가 데이터도 같은 팬페이지 경로 아래에 둔다. 예시 필드:

- `announcements`: 공지 항목 목록
- `schedule`: 방송 일정 목록
- `featuredLinks`: 추천 콘텐츠와 외부 링크 목록
- `updatedAt`: 최종 수정 시각

새 필드는 도입 시 서버 함수에서 형식·길이·항목 수를 검증한다. 권한은 요청 본문에 든 UID를 신뢰하지 않고, 인증된 UID와 서버가 조회한 `streamerVerifications`를 대조한다. 브라우저의 RTDB 직접 읽기·쓰기는 추가하지 않는다.

## 6. 초기에 미루는 항목

- 댓글·방명록·팬 게시판처럼 지속적인 신고·차단·관리 기능이 필요한 커뮤니티
- 결제, 후원, 재화 기능
- 공개 접속자 수나 개인별 방문자 추적

먼저 공지·일정·콘텐츠 이동을 안정적으로 제공하고, 실제 운영 요구가 확인되면 다음 단계에서 검토한다.

## 7. 기본 화면 흐름

```text
홈
 ├─ 스트리머 검색
 ├─ 최근 방문한 팬페이지
 └─ 팬페이지
     ├─ 프로필 · 방송국 바로가기
     ├─ 고정 공지
     ├─ 방송 일정
     ├─ 소개
     ├─ 추천 콘텐츠
     └─ 팬 소통 링크
```
